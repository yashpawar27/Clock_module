# Clock_module
This project used several integrated circuits to create an Astable 555 timer, a Monostable 555 timer, and a Bistable 555 timer. These timers work together in parallel to create a functioning clock module for an 8-bit breadboard computer.

Parts list:
- 1x SN74LS04N
- 1x SN74LS08N
- 1x SN74LS32N
- 3x NE555P
- 3x 1uF capacitor
- 4x LEDs
- 8x 1k resistors
- 1x 6mm momentary tact switch
- 1x Double throw toggle switch
